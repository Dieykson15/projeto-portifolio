Projeto Lista de Compras

Projeto construído para treinar conceitos essenciais de Front-end, construindo uma interface dinâmica de responsiva.

Saiba mais..

🛒 Lista de Compras
Um aplicativo web interativo para gerenciar listas de compras, desenvolvido como parte do desafio prático da Rocketseat. Este projeto tem como objetivo principal colocar em prática conceitos essenciais de Front-end, construindo uma interface dinâmica e responsiva.

🚀 Funcionalidades

  • Adicionar novos itens: Inserção rápida de produtos na lista de compras.
  • Remover itens: Exclusão fácil de produtos que não são mais necessários.
  • Marcar como comprado: Checkbox para alternar o estado visual dos itens que já foram colocados no carrinho.
  • Validação de entrada: Prevenção para não adicionar itens em branco ou inválidos na lista.
